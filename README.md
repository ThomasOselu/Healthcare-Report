# 🏥 Healthcare Report

## 📌 Overview
This project focuses on **cleaning, analyzing, and visualizing healthcare data** to uncover insights about patient admissions, treatment outcomes, and resource usage.  

---

## 🎯 Objectives
- Perform **data cleaning** to prepare healthcare datasets for analysis.  
- Build **visualizations** to show trends in patient admissions and outcomes.  
- Support decision-making in healthcare management.  

---

## 🛠 Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)  
- Excel (Data Preprocessing)  
- Power BI (Visualization)  

---

## 📊 Key Insights
- ⚕️ Peak patient admissions occurred during seasonal outbreaks.  
- 📉 Average hospital stay length reduced after new treatment guidelines.  
- 📈 Patient satisfaction scores improved by 15% in the last year.
